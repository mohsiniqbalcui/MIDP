Pie Chart Drawer Android App
This Android application allows users to input four numeric values and dynamically renders a pie chart based on those inputs. It demonstrates basic user input handling, data validation, and custom drawing using a View subclass.

🚀 Features
Input 4 positive integer values via EditText fields

Validate user input (no empty, zero, or negative numbers)

Dynamically render a pie chart with proportional segments

Clean, scrollable Material UI layout

Custom PieChartView class for drawing with Canvas

🛠 Built With
Android Studio

Java (or Kotlin if applicable)

Canvas API for custom drawing

XML layout with modern UI practices
